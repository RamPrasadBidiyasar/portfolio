Reactive watch-history platform

Serve high-volume user activity without letting a slow dependency hold up the whole response.

  • Reactive data access. Use Reactor Flux and reactive ScyllaDB repositories for history queries scoped to a user and profile.
  • Parallel composition. The query layer combines requested Continue Watching, history, favourites, and reactions sections with independent loaders.
  • Failure isolation. Per-section timeouts and empty-page fallback allow other sections to complete when one read fails.

ResultWatch-history re-architecture reduced P99 latency by 75% and improved per-instance throughput by approximately 4×.
